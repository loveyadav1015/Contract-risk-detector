# Data Directory

## Subfolders

### `raw/`
Place the original CUAD dataset files here. This includes:
- The CUAD JSON files (train/test splits)
- Any supplementary contract PDFs

**Do not commit raw data to version control.** The `raw/` directory is listed in `.gitignore`.

### `processed/`
This folder will contain processed and tokenized data generated by `src/dataset.py`. Outputs may include:
- Tokenized clause datasets (`.pt` or `.parquet` files)
- Label mappings
- Train/validation/test splits

**Do not commit processed data to version control.** The `processed/` directory is listed in `.gitignore`.
